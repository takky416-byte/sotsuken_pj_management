# 卒業研究 進捗管理アプリのご案内 (学生向け)

配布: 10/27 16:50 / 運用開始: 10/28 (水)

---

卒研のタスクと日報を管理するアプリを、10/28 から使います。

**URL: https://sotsuken-pj.web.app**

## 最初にやること (1分)
1. **Safari または Chrome** で上のURLを開く(LINEやメールのアプリ内ブラウザでは、ログインできないことがあります)
2. 「Googleでログイン」→ **@trident.ac.jp** のアカウントを選ぶ
3. 自分のチームの画面が出れば完了。出ない場合は、先生に連絡してください
4. **このURLを、お気に入り(ブックマーク)に追加**しておく(毎日開きます。ホームに追加のしかたが出ます)

## 何ができるか
- **WBS**: チームのタスクを一覧で見て、追加・編集・状態の変更ができます。チームの全員が、お互いのタスクを直せます。自分の担当は、タスクに「自分」を付けてください
- **日報**: 授業日にだけ書きます(**当日中は何度でも直せます**)。**授業時間外にやった作業も含めて、前回の日報のあとにやったことを、まとめて書きます**。やった項目を選び、それぞれに何をどこまでやったかを書きます
- **ミーティング画面**: 週1回(木曜2限)、1チーム10分。同じ画面を見ながら話します

## 日報の書き方
1. 「日報」を開く
2. 前回の日報のあとにやったタスクにチェックを入れる(授業時間外の作業も含む)
3. それぞれに一言(例:「調査を終えた」「ここで詰まっている」)
4. 提出

## リマインドメール
授業日の 16:30 ごろ(木曜は 10:45 ごろ)、日報を出していない人へ、先生のアドレスから「卒研PJ管理(自動送信)」として届きます。迷惑メールに入っていないか確認してください。

## 知っておいてほしいこと
- 先生は、**すべてのチームの内容**を見られます。他のチームの内容は、学生には見えません
- 先生だけが見るメモがあります(学生には表示されません)
- 欠席の扱いは、先生が入力します
- ファイルのアップロードはできません。資料はGoogleドライブに置き、チームの画面にリンクを貼ってください

## アプリの使い方・不具合
アプリの使い方で分からないこと、不具合は、先生(yoichiro.takikawa@trident.ac.jp)まで。
卒研の進め方は、先生に聞くのではなく、チームで相談して決めます。
