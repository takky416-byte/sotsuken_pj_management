# 卒研の成果物 (叩き台に、必ず入れる)

教員から共有された、あらかじめ決まっている成果物の一覧 (2026-10-26)。初期WBS(叩き台)は、これを背骨にして作る。
中身は `app/src/lib/deliverables.ts`。叩き台の点検 (`npm run check-draft`、キックオフ画面) が、抜けを誤りとして知らせる。

## 中間報告までの成果物 (中間報告は対面レビュー = 11/25 の外部設計レビューとみなす)
設計書類 (事前送付):
- 要件定義書 / 画面レイアウト / 画面遷移図 / 機能仕様書 / ER図 / テーブル定義書 / 回路図 / システム構成図

試作品:
- 中間報告の際に見せられるもの

## 最終報告までに用意するもの (最終報告はプレゼン方式 = 1/26 の最終レビューとみなす)
- 発表スライド (事前送付)
- 最新化した設計書類 (事前送付)
- デモンストレーションの準備 (当日にデモを見せられない場合は、デモ動画)

## 卒展 (2/6) までに用意するもの
- 操作説明書 / 卒展のシフト表 / アプリ説明用スライド / アプリ説明動画 / 動画のYouTube限定公開 (1/27締切) / 卒展用パネル / ソースコード一式(卒展までに提出。2026-10-26 追加)

## 記入サンプルから分かったこと (2026-10-26。「記入サンプル/25SF1D」の中身)
サンプルは、前年度の1チームの提出物一式 (ハード+ソフト: Raspberry Pi の調理おもちゃ + スマホのWebアプリ)。氏名が入っているので、リポジトリには入れていない (要点だけ書く)。

- **設計書類は、Excelの定型の用紙に記入する形**。1シートごとに、上の見出しに「論理名称・物理名称・システムID・システム名称・改訂日・改訂者・備考」がある。ファイル名は、番号つき: 01要件定義、02画面レイアウト、03画面遷移図、04機能仕様書、07回路図、09システム構成図。
  - 05・06・08 は、フォルダに入っていなかった (05=ER図、06=テーブル定義書、08=?と思われるが、未確認)。
- **01 要件定義**: 機能要件を番号つきで、1つずつ「どのような機能か」「入力・表示・処理は何が必要か」を書く。ハードとソフトは、別のシートに分けて書いていた。
- **02 画面レイアウト**: 画面ごとに1シート。「項目名称 / 入力か表示か / 種類(ボタン・文字・画像・日付など)」の表と、レイアウトの図。
- **03 画面遷移図**: 画面どうしの矢印の図 (シートは図が中心)。
- **04 機能仕様書**: 「機能概要 / イベント / 処理内容」を、機能ごとに並べる。ソフト(スマホ)とハード(ラズパイ)で、シートを分ける。
- **07 回路図**: 部品表 (名前・数・規格。抵抗の値、ジャンパーケーブルの本数など)と、回路の図。部品表は、機材発注 (11/5・12/1) のもとになる。
- **09 システム構成図**: 構成の図。
- **発表スライド(企画説明)**: 16枚ほど。表紙 → 作品を一言で → 内容 → 発案のきっかけ → 実演/操作説明の動画 → ペルソナ → 概要図 → モード説明 → ライバルと差別化 → メリット → マネタイズ(材料費・人件費・販売価格案・コストダウン案) → 使用技術 → 今後の展望 → 終わり。
- **操作説明書**: PDFで1〜2ページ。実機の各部に番号を付けて説明し、Webアプリの操作を、番号つきの手順と図で示す。
- **アプリ説明動画**: mp4と、YouTubeの限定公開のURLを書いたテキストファイル。
- **シフト表**: 卒展の対応当番。10:00〜16:00を30分ごとの枠にして、担当者と休憩を書く。
- **ファイル名**: 「日付(YYMMDD)+成果物の名前+_チーム記号」(例: 260105操作説明書_D)。

### 叩き台に反映したこと
- 項目の「やること・できあがり」を、上の用紙の形 (画面ごとに1シート、改訂日・改訂者、機能概要・イベント・処理内容、部品表つきの回路図) に合わせた。
- 発表スライドの構成から、「ペルソナ」「費用の見積もり(材料費・開発費・人件費)」「今後の展望」の項目を足した (なければ点検で注意が出る)。
- ハード系の見本 (`docs/wbs-drafts/example-hard.md`) を足した (回路図と部品表・発注2回・組み立てを入れ、ER図とテーブル定義書を外した)。
- 「アプリ説明用スライド」は、サンプルの「卒業制作展用企画説明」と同じものとして、題名に「企画説明」とあっても成果物とみなす。

### 確認したいこと
- 05・06・08 の用紙(ER図・テーブル定義書など)のサンプルは、ありますか。
- 「発表スライド」(最終報告)と「アプリ説明用スライド」(卒展)は、同じスライドを使い回しますか。(サンプルは1つのスライドで、表紙に「最終発表」とあり、ファイル名は「卒業制作展用企画説明」。)
